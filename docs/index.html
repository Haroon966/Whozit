Why Whozit

Faces for your app, without the research lab

Mobile apps, kiosks, door cameras, and scripts often need a head count or face crops. Embedding SCRFD and ArcFace everywhere is heavy. Whozit wraps detection and recognition in a normal HTTP API.

One contract, many clients

Post an image — multipart or base64 JSON. Get structured JSON back: count, boxes, crops, optional identity. Works from any language.

Path to attendance

Detect → crop → enroll → recognize → log presence. Same stack from a head-count MVP to daily attendance scans.

What it does

Detect, enroll, recognize, log

Own SCRFD + ArcFace under whozit/ (adapted from UniFace, MIT). FastAPI server plus a simple UI for local use.

  • v1

    Detect faces

    Face count plus base64 head crops with configurable padding, confidence threshold, crop format, and landmarks. No faces still returns clean JSON.

    POST /v1/detect
  • v1 / v2

    Enroll people

    Store a name and face embedding. List or delete people anytime.

    POST /v2/enroll
  • v2

    Recognize names

    ArcFace match against enrolled faces. Matched names or unknown, with scores.

    POST /v2/recognize
  • v2

    Log attendance

    Recognize and append matched people to attendance events — one event per person per request — then query the log with a simple GET.

    POST /v2/attendance
How it works

Three steps to structured results

Run locally with uvicorn or Docker. First start downloads SCRFD + ArcFace weights into a cache directory.

Upload a photo

Multipart form or JSON base64 to detect, recognize, or attendance endpoints.

SCRFD + ArcFace

In-repo engine detects faces, crops heads, and optionally matches embeddings.

Get JSON

Face count, crops, names, match scores, and attendance events when you ask.

Privacy: uploaded images are not persisted by default. Disk stores face embeddings and attendance events only — not raw photos. Prefer an API key on any network-exposed deploy.

Get the code

Clone the repo, install requirements, run uvicorn on port 8088. Full setup and curl examples live in the README.
