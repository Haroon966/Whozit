Integrate with cURL

Use these from your app. Base URL is this server. Optional: X-API-Key if configured.

Detect + identify 
curl -s -X POST "__BASE__/v1/detect" \
  -F "image=@photo.jpg" \
  -F "identify=true" \
  -F "square=true" | jq .
Detect (JSON base64) 
B64=$(base64 -w0 photo.jpg)
curl -s -X POST "__BASE__/v1/detect" \
  -H "Content-Type: application/json" \
  -d "{\"image_base64\":\"$B64\",\"identify\":true}" | jq '{face_count, faces: [.faces[] | {id, name, matched}]}'
Recognize (v2) 
curl -s -X POST "__BASE__/v2/recognize" \
  -F "image=@photo.jpg" | jq '{face_count, faces: [.faces[] | {id, name, matched, match_score}]}'
Attendance (v2) 
curl -s -X POST "__BASE__/v2/attendance" \
  -F "image=@photo.jpg" | jq '{face_count, attendance, faces: [.faces[] | {id, name, matched}]}'

curl -s "__BASE__/v2/attendance?limit=20" | jq .

  -F "name=Ali" \
