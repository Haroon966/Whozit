Integrate with cURL

Use these from your app. Base URL is this server. Optional: X-API-Key if configured.

Detect + identify 
curl -s -X POST "__BASE__/detect" \
  -F "image=@photo.jpg" \
  -F "square=true" | jq .
Detect (JSON base64) 
B64=$(base64 -w0 photo.jpg)
curl -s -X POST "__BASE__/detect" \
  -H "Content-Type: application/json" \
  -d "{\"image_base64\":\"$B64\",\"square\":true}" | jq '{face_count, faces: [.faces[] | {id, confidence}]}'
Recognize 
curl -s -X POST "__BASE__/recognize" \
  -F "scope_key=pk/lahore-east/school-abc/class-5a" \
  -F "image=@photo.jpg" | jq '{face_count, unknown_count, faces: [.faces[] | {id, name, matched, score}]}'
Daily register 
curl -s -X POST "__BASE__/attendance/day" \
  -H "Content-Type: application/json" \
  -d '{"scope_key":"pk/lahore-east/school-abc/class-5a","date":"2026-08-18","present_ref_ids":["REF_ID"]}' | jq .

curl -s "__BASE__/attendance/day/status?scope_key=pk/lahore-east/school-abc/class-5a&date=2026-08-18" | jq .

Integrate with cURL

Enroll faces from your app, then match with detect or recognize.

Enroll 
curl -s -X POST "__BASE__/enroll" \
  -F "scope_key=pk/lahore-east/school-abc/class-5a" \
  -F "name=Ali" \
  -F "image=@ali_face.jpg" | jq .
With API key 
curl -s -X POST "__BASE__/enroll" \
  -H "X-API-Key: your-secret" \
  -F "scope_key=pk/lahore-east/school-abc/class-5a" \
  -F "name=Ali" \
  -F "image=@ali_face.jpg" | jq .
